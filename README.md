# Lawyer Archives

A mobile application for managing lawyer-related archives, built with Android and Kotlin. This project uses modern
Android development practices, including View Binding, Material Design, and Persian Calendar View.

## Features

- Display and manage lawyer archives.
- Persian calendar integration for date selection.
- Material Design components for a modern UI.
- Support for Android API 23 and above.
